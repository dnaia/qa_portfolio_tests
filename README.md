# CREDIT CARD

Backend сервиса кредитной карты — часть сервисов мобильного банкинга, предоставляющая API для управления кредитным продуктом.

## Функциональность сервиса

* Авторизация пользователя
* Изменение информации о владельце карты
* Открытие кредитной карты
* Закрытие кредитной карты
* Получение информации по кредитной карте
* Увеличение кредитного лимита

Документация API доступна после локального запуска приложения:

```
http://localhost:22500/docs
```

# Автоматизированное тестирование

Проект содержит набор backend API автотестов, реализованных с использованием Python и pytest.

## Используемый стек

* Python
* Pytest
* Pytest-asyncio
* HTTPX
* SQLAlchemy
* Faker
* Poetry
* Docker
* Docker Compose

## Покрытие тестами

### Авторизация

* успешная авторизация;
* авторизация с неверными учетными данными;
* проверка обязательных полей.

### Пользователь

* изменение информации владельца карты;
* получение информации о пользователе;
* проверка сохранения изменений.

### Кредитная карта

* открытие кредитной карты;
* закрытие кредитной карты;
* получение информации по карте;
* увеличение кредитного лимита;
* позитивные и негативные сценарии.

### Сервис

* проверка healthcheck endpoints;
* проверка метрик;
* проверка бизнес-логики сервиса.

## Что проверяют тесты

* HTTP status codes;
* JSON response;
* корректность данных;
* валидацию входных параметров;
* позитивные сценарии;
* негативные сценарии;
* граничные значения.

## Запуск проекта

Установка зависимостей:

```bash
poetry install
```

Запуск тестов:

```bash
poetry run pytest
```

Запуск с подробным выводом:

```bash
poetry run pytest -v
```
